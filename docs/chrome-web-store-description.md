# Chrome Web Store Listing

## Product Name

Hover Sinhala Translator

## Short Description

Hover over an English word to see its Sinhala meaning.

## Detailed Description

Hover Sinhala Translator helps readers understand English words without leaving the page. Move the cursor over a supported word, wait for the configured delay, and view its Sinhala translation in a compact popup. Users can configure the delay, popup position, and optional definition and part-of-speech display.

## Category and Language

- Category: Productivity
- Primary language: English
- Translation target: Sinhala

## Permissions

The `storage` permission stores user preferences such as hover delay and popup display settings. The extension does not request tabs, history, bookmarks, cookies, or geolocation permissions.

## Privacy

The hovered word is sent to the configured FastAPI backend for translation. The extension does not send page contents, history, cookies, passwords, or form contents.
